MoveCraft · 体感荒岛   一键版
========================================

【怎么玩】

  1. 把整个压缩包解压到一个文件夹
     （右键压缩包 → 全部解压缩。不要直接在压缩包里双击，
       也不要只复制其中几个文件。）

  2. 双击「双击启动游戏.bat」

  3. 会弹出一个黑色的命令行窗口，同时浏览器自动打开游戏。
     如果浏览器没自动打开，把窗口里显示的地址
     （形如 http://localhost:8787）复制到 Chrome 或 Edge 打开。

  4. 玩的时候第一次点「开启摄像头」，浏览器会询问是否允许，
     点「允许」即可。

  5. 玩完直接关掉那个黑色窗口，游戏就停了。


【不用装任何东西】

  这个版本自带运行环境，不需要安装 Python，也不需要联网。
  全程离线运行，摄像头画面不会上传到任何地方，存档保存在
  你自己的浏览器里。


【如果摄像头打不开】

  电脑上装了 Iriun、DroidCam、OBS 这类「用手机当摄像头」的
  软件时，它们会挤掉真正的摄像头。游戏页面有一个「摄像头」
  下拉框，改成 Integrated Camera（内置摄像头）一类的名字即可。

  页面底部还能导出 / 导入存档，换浏览器或换电脑时用得上。


【常见问题】

  问：双击后窗口一闪就没了？
  答：说明解压不完整。请重新完整解压压缩包再试。

  问：提示端口被占用？
  答：程序会自动换到 8788 等端口，看窗口里显示的地址即可。

  问：浏览器打开是空白 / 画面卡住？
  答：请用较新的 Chrome 或 Edge；不要用 IE 或很旧的浏览器。

  问：能发给别人吗？
  答：可以，整个文件夹压缩后直接发，对方解压双击即可。


请量力运动，保持场地平整、周围无障碍物。
