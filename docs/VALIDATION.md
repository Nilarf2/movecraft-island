## 摄像头选择器（2026-10-22 补充）

Windows / Chrome 实机追加验证：

- 登录页与体感游戏页各有一个摄像头下拉框；选择「自动选择」时沿用系统默认设备，选择具体设备时用 `deviceId: {exact}` 精确打开，不再受 `facingMode` 干扰。
- 设备名以 `Iriun / DroidCam / OBS Virtual / 虚拟摄像头` 等关键字标注为「虚拟设备」，提醒用户这类设备需要配套手机 App 或软件在运行。
- 选择结果写入 `movecraft.island.v1.device`，刷新后自动恢复；设备被拔掉后第一次枚举会清除过期偏好并退回系统默认。
- 失败回退已实测三种场景：存了已拔掉的设备 id、所选设备 `NotReadableError`、枚举不到任何摄像头，都能正常退回默认设备或给出可操作的提示，选择器保持可用。
- 真实设备验证：机器同时存在 Iriun Webcam（虚拟）与 Integrated Camera，选择器正确列出两者；选中内置摄像头后 MediaPipe 推理持续输出 9～14 FPS、单帧 33～47 ms，镜像画布同步绘制，无 pageerror。
- `npm test` 18 个测试通过；浏览器回归覆盖规则倒计时、摄像头拒绝、四关完整试玩、奖励兑换、存档恢复与 390×844 布局无水平溢出。

尚未进行真人摄像头运动验收，尤其需要实际评估竖直跳与深蹲在不同机位、光线和人体条件下的效果。软件仅处理单人画面。
