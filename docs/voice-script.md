# 配音台本

台本源头是 `web/narration.js`。`scripts/generate_voice.py` 读取 `allVoiceLines()`，用 Gemini TTS（`gemini-3.8-flash-tts`，音色 Puck）生成配音，每条录音以台词原文为键写入 `web/voice-assets.js`；某句的录音不全时，整句改用设备中文语音。改了台词要重新生成配音，`tests/narration.test.mjs` 会发现没有对应台词的旧录音。

## 人设

荒岛向导：亲切、有活力，像站在身边带练的真人教练。说口语短句，报数干脆，提醒具体温和，完成时真心为你高兴，不喊口号。屏幕上的说明保持完整，语音只说下一步要做什么。

## 一轮里会听到什么

- 规则：「欢迎来到体感荒岛！竖直跳摘椰子换淡水，开合跳砍树攒木材，手臂平举耕种收粮食，深蹲盖房子。每项从十个开始，每两天加一个，最多二十五个。每天都要喝水吃饭，生命归零就挑战失败。留出活动空间，量力而行。准备好了，就挥手登岛吧！」
- 登岛：「摄像头准备好了。右手向右侧平举，停一下，再往左挥，就能登岛。」
- 进第一关：「登岛成功！第一站，摘椰子！来十个竖直跳，换点淡水。双脚一起跳起来，再稳稳落地。记得让双脚都在画面里。」
- 报数：「三！」
- 过半：「五！过半了，保持节奏！」
- 节奏放慢：「四！保持这个节奏！」
- 还剩三个：「七！还剩三个，坚持住！」
- 最后一个：「九！最后一个！」
- 完成第一关：「十！椰子摘够了，淡水加两份！」
- 中途回来：「继续砍树！还差七个。跳开时双手举过头顶，收脚时放下手臂。」
- 纠正：「往后退一点，让肩膀、膝盖和双脚都在画面里。」
- 建房完成：「十！简陋棚屋搭好了！」
- 结算：「这一轮全部完成，辛苦啦！竖直跳、开合跳、手臂平举和深蹲各做了十个，一共消耗三十五卡。你击败了全国百分之九十八的人！热量和排名都是游戏换算的鼓励，不是真实测量。每一个动作都算数。好好休息，明天岛上见！」
- 次数不一致的旧存档结算：「这一轮全部完成，辛苦啦！每项的次数和热量都在屏幕上。你击败了全国百分之九十八的人！热量和排名都是游戏换算的鼓励，不是真实测量。每一个动作都算数。好好休息，明天岛上见！」
- 失败：「生命值归零，这次挑战结束了。休息好了，随时可以重新开岛。」

## 模板说明

- 关卡开场：四关 × 目标 10–25 个，整句录制，数字不拼接。
- 中途回来：「继续摘椰子！」类开头 4 条，加「还差一个。」到「还差二十四个。」。
- 报数：「一！」到「二十五！」单独录制，里程碑和奖励是紧跟其后的独立短句，在句末衔接。
- 结算：四项次数相同（正常一轮）时，「各做了 N 个，一共消耗 X 卡。你击败了全国百分之 P 的人！」整句录制，N 为 1–25；次数不一致的旧存档改说「每项的次数和热量都在屏幕上」，再接排名。
- 超出范围的数字（如目标超过 25）没有录音，整句用设备语音朗读。
